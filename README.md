# Голосовой сервер CyberFaceit

Голос между игроками идёт напрямую (WebRTC), этот сервер только соединяет игроков друг с другом
и выдаёт настройки TURN. Если сервер недоступен, страница сама переключается на старый канал через Firestore.

## Запуск (1 минута)
```
cd voice-server
cp ../index.html .        # чтобы сервер отдавал и сайт (необязательно)
node server.js            # нужен Node.js 18+
```
Проверка: открыть `http://localhost:8080/health` → `{"ok":true,...}`.

## Подключение страницы
- Если сайт открывается С ЭТОГО ЖЕ сервера (`/`) — ничего менять не нужно.
- Если сайт лежит в другом месте (Firebase Hosting и т.п.) — в `index.html` найдите строку
  `const VOICE_SERVER='';` и впишите адрес: `const VOICE_SERVER='wss://voice.ваш-домен.ru/ws';`
- Нужен HTTPS/WSS (микрофон в браузере работает только по HTTPS). Бесплатные варианты: Render, Railway, Fly.io,
  либо свой VPS + Caddy/nginx с сертификатом.

## TURN — обязательно для «чёткого» голоса на мобильной связи
Без TURN часть игроков (мобильный интернет, строгие роутеры) не услышит друг друга. Три способа:
1. **Свой coturn** (лучшее качество): `docker compose up -d`, поправив домен/IP/секрет в `docker-compose.yml`
   и `coturn/turnserver.conf`. Порты: 3478 tcp/udp, 5349, 49160–49200 udp.
2. **Metered.ca** (готовый сервис): переменные `METERED_DOMAIN`, `METERED_API_KEY`.
3. Один статический логин: `TURN_URLS`, `TURN_USER`, `TURN_PASS`.

## Переменные окружения
| Переменная | Значение |
|---|---|
| `PORT` | порт (по умолчанию 8080) |
| `FIREBASE_PROJECT_ID` | по умолчанию `nsnsjsb-15907` — токены игроков проверяются |
| `REQUIRE_AUTH` | `0` — отключить проверку токена (только для тестов) |
| `ALLOWED_ORIGINS` | адреса сайта через запятую, например `https://cyberfaceit.ru` |
| `TURN_URLS`, `TURN_SECRET` / `TURN_USER`, `TURN_PASS` | свой TURN |
| `METERED_DOMAIN`, `METERED_API_KEY` | TURN от Metered |
| `MAX_ROOM` | игроков в комнате (по умолчанию 10) |

Что изменено в `index.html`: свой сервер сигналов, Opus-настройки для голоса (моно 48 кГц, FEC, ~40 кбит/с),
авто-переподключение, повторная попытка при обрыве, замена микрофона на лету,
и исправлена ошибка, из-за которой голос пати выключался сразу после включения.
